# 🌍 LingWei's Development Workspace: SKILL & MCP

[*🌐 Read in Chinese (切换至中文版本)*](#chinese-version)

Welcome to my central development repository! This workspace is dedicated to housing scripts, tools, and server architectures across two distinct yet powerful technology domains: **EDA Automation (SKILL)** and **AI Context Integration (MCP)**.

## 🚀 Project Overview

This repository is divided into two main modules:

1. **[SKILL](./SKILL/)**: Focuses on Cadence SKILL language development. It contains scripts and utilities for Electronic Design Automation (EDA), aiming to automate layout design, schematic generation, and IC design workflows in the Virtuoso environment.
2. **[MCP](./MCP/)**: Focuses on the Model Context Protocol. It contains server implementations (MCP Servers) that allow large language models (like Claude) to securely interact with local tools, external APIs, and internal datasets.
